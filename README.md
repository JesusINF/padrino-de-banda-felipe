# Felipe, padrino de banda

Invitación web móvil para Felipe como padrino de banda. Sitio estático en HTML, CSS y JavaScript, con persistencia segura en el mismo proyecto Firebase de las invitaciones de boda.

Sitio público: https://jesusinf.github.io/padrino-de-banda-felipe/

## Validación local

```powershell
npm run check
npm run serve
```

## Seguridad

La configuración incluida es la configuración pública del cliente Firebase. Las reglas de Firestore permiten crear exactamente una respuesta válida para `felipe-banda` y niegan lectura, actualización o eliminación desde el cliente.
